# SpendWise Dashboard Shell

## Project Description

SpendWise is a personal finance dashboard designed to help users
monitor their income, expenses, savings, and financial activities.

The project uses HTML5 and CSS3 to create a clean, modern,
responsive dashboard interface.

## Features

- Sidebar navigation menu.
- Dashboard header and user profile.
- Total balance summary.
- Total income summary.
- Total expenses summary.
- Six financial category cards.
- Recent financial activities.
- Responsive mobile layout.
- Automatic dark theme.
- Card hover animations.
- Keyboard focus animations.

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS Custom Properties
- Media Queries

## Project Structure

- index.html: Contains the dashboard structure and content.
- style.css: Controls the layout, colors, animations,
  responsiveness, and dark theme.
- README.md: Explains the project and its features.

## CSS Grid and Flexbox

CSS Grid is used for the overall dashboard layout,
summary cards, and expense category cards.

Flexbox is used for the sidebar navigation,
header, profiles, and individual dashboard cards.

## Responsive Design

The project uses a media query:

@media screen and (max-width: 768px)

The dashboard changes to a single-column layout
on smaller screens.

## Dark Theme

The project supports automatic dark mode using:

@media (prefers-color-scheme: dark)

Dark mode overrides the CSS custom properties
defined inside the :root selector.

## Card Micro-interactions

Dashboard cards use:

- transform
- box-shadow
- transition

Animations last 200 milliseconds and work
with mouse hover and keyboard focus.
